第三步：软件接入

接口地址怎么填、密钥怎么用、各客户端一览

不管用哪个客户端，都只需要两样东西：

1. 接口地址（Base URL）

本站的接口地址是：

text
https://api.juheai.shop

要不要带 /v1 ，取决于客户端用哪种协议 ：

协议地址哪些客户端
Anthropichttps://api.juheai.shopClaude Code CLI / 桌面端、CC Switch 的 Claude 配置
OpenAI 兼容https://api.juheai.shop/v1Codex CLI / 桌面端、Codex++、CC Switch 的 Codex 配置、酒馆等图形客户端

每个客户端章节里都会再写一次该填哪个。

2. API 密钥

在网站的「API 密钥」页面创建一把密钥，形如

sk-xxxxxxxx 。创建后请立即复制保存 ——

离开页面后就无法再看到完整内容。

密钥等同账号凭证。

不要把它贴到聊天群、截图或公开仓库里。怀疑泄露时，回到「API 密钥」页面

删除该密钥并重新创建一把。

遇到问题先看这里。

模型名写错是新手最容易踩的坑。每个客户端章节末尾都有该工具常见问题的排查步骤。

还是搞不定？ 把这三样发给客服，基本一看就知道问题在哪：① 终端里最后 5～10 行文字（可截图，注意别拍到密钥）② 你在本页做到第几步 ③ 报错的原文或截图。密钥属于隐私，发送前可以先给后几位打码。

每个客户端都是独立的一页，安装方式、配置位置、要填的字段都不一样，别把不同工具的做法混用。

标了「无需写代码」的是图形界面客户端 ——打开设置、填接口地址和密钥、选模型即可，全程点一点；

命令行类（CLI）按页内命令操作。

Claude 系

Claude Code CLI 命令行

命令行工具。装好后在终端里用 claude 启动，按页内命令填参数。

Claude Code 桌面端 无需写代码

Claude 桌面应用的 Code 选项卡。在设置里填接口地址、密钥、选模型即可。

Codex 系

三个不同的东西 ，其中 Codex++ 是第三方工具。

Codex CLI 命令行

OpenAI 官方命令行工具。用 codex 启动，按页内命令配置。

Codex 桌面端 无需写代码

OpenAI 官方图形应用。在设置里填地址和密钥，与 CLI 共用同一份配置。

Codex++ 无需写代码

第三方启动器。给 Codex 桌面端做供应商切换与增强，纯界面操作。

统一管理 / 其他

CC Switch 无需写代码

跨平台桌面应用，统一管理 10 个 AI 编程工具的供应商配置，图形界面切换。

Agent 框架

DeepSeek Harness 命令行 / Web

DeepSeek 官方开源 Agent 框架，Web UI / Headless 双模式。

Hermes Agent 命令行 / TUI

Nous Research 自主 Agent，CLI / TUI / 多端运行。

OpenClaw 命令行 / 配置

最火的开源个人 Agent。接到 Telegram / Discord / Slack，在你自己电脑上干活。

聊天 / 角色扮演

酒馆 SillyTavern 无需写代码

角色扮演 / 聊天前端。OpenAI 兼容接口，在设置里填一个端点和密钥就能用。
