Cherry Studio / ChatBox / NextChat

这类聊天客户端都走 OpenAI 兼容协议，配置大同小异：

text
API 地址：https://api.juheai.shop
API 密钥：sk-xxxxxxxx
模型：deepseek-v4.1-flash（举例，以模型广场为准）

添加模型时，如果客户端要你手填模型 ID，就从模型广场复制，别手打。

Cursor

Cursor 用的是 OpenAI 协议，在 Settings → Models → OpenAI API Key 里：

  1. 勾选 Override OpenAI Base URL
  2. Base URL 填 https://api.juheai.shop/v1
  3. API Key 填你的密钥
  4. 点 Verify 验证

Cursor 这里需要带 /v1，它不会自动补。这是最容易搞错的地方。

Claude Code

Claude Code 走 Anthropic 协议，需要配环境变量：

bash
export ANTHROPIC_BASE_URL=https://api.juheai.shop
export ANTHROPIC_AUTH_TOKEN=sk-xxxxxxxx

注意：Claude Code 必须用支持 Anthropic 协议的分组。如果你的密钥是纯 OpenAI 分组，会报 This group does not allow /v1/messages dispatch。

不知道自己该用哪个协议？

记住一句话：

你用的客户端协议密钥要求
Cherry Studio、ChatBox、CursorOpenAI任意分组
Claude Code、Claude 官方客户端Anthropic必须支持 Anthropic 的分组

不确定就问客服，别自己猜。
