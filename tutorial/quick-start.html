快速开始：三步接入

注册、创建密钥、填入客户端，五分钟跑通第一个请求

第一步：登录控制台

打开 Sub2API 控制台，用注册的邮箱登录。

登录后先看一眼余额，新账户可能有免费额度，也可能需要先充值。

第二步：创建密钥

进入「密钥」页面，点「新建密钥」，然后：

  • 选择分组：不同分组对应不同的模型和价格，不确定就先用默认分组
  • 设置名称：随便起个名字，方便以后区分（比如「Cherry 用」）
  • 设置额度：可选，不填就是不限

创建后会得到一串以 sk- 开头的字符串。这串东西只显示一次，一定复制保存好。

密钥等同于你的账号密码。不要发给任何人，也不要提交到 Git 仓库。

第三步：填入客户端

以 Cherry Studio 为例，在设置里添加一个 OpenAI 兼容的服务商：

配置项填什么
API 地址https://api.juheai.shop
API 密钥刚才复制的那串 sk-...
模型从控制台的「模型广场」复制模型名

保存后发一条消息测试，能正常回复就算接通了。

常见卡点

  • 地址结尾不要加 /v1，多数客户端会自动补，加了会变成 /v1/v1
  • 密钥首尾不要有空格，从网页复制常带换行
  • 模型名要完全一致，包括大小写和连字符
