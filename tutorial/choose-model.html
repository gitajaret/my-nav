一、四个家族，各有什么特点

DeepSeek 系列

特点说明
价格最便宜，通常是其他家的几分之一
速度快
中文很强，中文语感好
代码中上水平
适合日常问答、翻译、批量处理、省钱场景

一句话：性价比之王，日常活儿全交给它。

GPT 系列

特点说明
价格中等
速度中等（推理版慢）
强项逻辑推理、数学、结构化输出
弱项中文写作不如 Claude 自然
适合复杂问题分析、需要严谨推理的任务

一句话：脑子最清楚，适合需要「想明白」的活儿。

Claude 系列

特点说明
价格偏贵
速度中等
强项写代码、长文写作、理解复杂需求
弱项贵，不适合大批量
适合编程、正式文档、需要「写得像人」的场合

一句话：文笔和代码最好，但用起来心疼。

Gemini 系列

特点说明
价格便宜到中等
速度快
强项超长上下文、多模态（看图）
弱项中文写作一般
适合处理超长文档、需要看图的任务

一句话：能吃下超长内容，看图的活儿找它。

二、按场景选（最实用的一节）

场景 1：写代码 / 修 bug

text
首选：Claude 系列
理由：代码能力最强，能理解整个项目的上下文
备选：GPT 系列（推理版）
省钱：DeepSeek 也能写，简单脚本完全够用

建议：

任务用哪个
写个小脚本DeepSeek 就够
改复杂 bugClaude
重构一个模块Claude
解释一段看不懂的代码DeepSeek 或 Claude

场景 2：写文案 / 文章

任务用哪个原因
正式文档、公文Claude语感自然，不啰嗦
公众号、小红书Claude 或 DeepSeek看预算
简单改写、缩写DeepSeek够用且便宜
翻译DeepSeek中文理解好，价格低

场景 3：日常问答 / 学习

直接上 DeepSeek 快速版。

text
问个概念、查个用法、解释个词 → 快速模型足够
用贵的模型问这些，纯属浪费钱

场景 4：数学 / 逻辑题

任务用哪个
计算、证明、推理GPT 推理版
简单算术任何模型
需要多步推理GPT 推理版（开高推理档）

注意：推理版模型响应慢，因为它会「先想再答」。别用它做简单任务。

场景 5：超长文档

文档长度怎么办
1 万字以内任何模型都行
1-10 万字用长上下文模型（Gemini 或标注长上下文的）
10 万字以上分段处理，别硬塞

分段处理的正确姿势：

text
第 1 步：让 AI 逐段总结（每段 1 万字）
第 2 步：把各段总结合并，再让它做整体分析
第 3 步：针对具体问题，回原文找细节

场景 6：批量处理

比如翻译 100 个文件、总结 50 篇文章。

text
原则：能用便宜的就不用贵的
首选：DeepSeek 快速版
理由：便宜 + 够快 + 中文好
100 个文件的成本可能只差几十倍

三、怎么省钱（重点）

省钱法则 1：先试便宜的

text
先用 DeepSeek 试 → 效果满意？结束
                → 不满意？换 Claude 再试

很多人一上来就用最贵的，其实便宜的就够了。

省钱法则 2：控制对话长度

上下文越长，每次请求越贵。

情况相对成本
新对话问一句1 倍
带着 10 轮历史5-10 倍
带着 5 万字文档50-100 倍

做法：

text
✓ 换话题就开新对话
✓ 不需要的历史手动删掉
✓ 大文档处理完就关掉
✗ 不要在一个对话里聊一整天

省钱法则 3：控制输出长度

输出比输入贵（通常是 2-4 倍）。

说法成本
「详细展开，越详细越好」高
「简要说明要点」低
「用 3 句话总结」最低

省钱法则 4：别用推理版做简单事

text
❌ 用推理版问「今天天气怎么样」
✓ 用快速版问

推理版会生成大量思考过程，费用是快速版的数倍

省钱法则 5：用缓存

部分模型支持「缓存读取」，重复用同一段长内容时费用大幅降低。

适用场景：

text
同一份文档，反复问不同问题
同一个系统提示词，反复调用

四、常见误区

误区 1：「越贵的越聪明」

不一定。 不同模型擅长不同的事。

任务贵模型表现便宜模型表现
日常问答好一样好
翻译好差不多
复杂代码明显更好一般
长文写作明显更好一般

结论：简单任务用贵的纯属浪费。

误区 2：「一个模型走天下」

不同任务换不同模型，效果好还省钱。

text
写代码 → Claude
问问题 → DeepSeek
算数学 → GPT 推理版

误区 3：「模型名越新越好」

新版有时会「变懒」或风格改变。用得顺手就别轻易换。

误区 4：「回答不好是模型不行」

八成是提示词的问题。

症状真正原因怎么改
回答太笼统问题问得太宽加具体要求和例子
答非所问没说清要什么明确说「我要 X 格式的回答」
太啰嗦没限制长度加「用 3 句话」
不准确没给背景提供相关资料

五、决策流程图

text
开始
 │
 ├─ 是简单问答/翻译？
 │    └─ 是 → DeepSeek 快速版，结束
 │
 ├─ 要写代码？
 │    ├─ 简单脚本 → DeepSeek
 │    └─ 复杂项目 → Claude
 │
 ├─ 要数学推理？
 │    └─ 是 → GPT 推理版
 │
 ├─ 文档超过 10 万字？
 │    ├─ 是 → Gemini 或分段处理
 │    └─ 否 → 继续
 │
 ├─ 要批量处理（100+ 次调用）？
 │    └─ 是 → 选最便宜的能用的
 │
 └─ 其他 → DeepSeek 先试，不满意再升级

六、模型名在哪查

本文不写具体模型名，因为会变。 正确做法：

text
1. 登录控制台 https://api.juheai.shop
2. 打开「模型广场」
3. 看当前可用的模型列表和价格
4. 点「复制」拿到准确的模型名
5. 粘贴到客户端里

模型名必须从模型广场复制，不要手打。

大小写、横杠、版本号错一个字符都会报 404。

七、三个实用组合

组合 A：极致省钱

text
全部用 DeepSeek 快速版
适合：日常使用、批量任务
成本：最低

组合 B：平衡型（推荐）

text
日常 → DeepSeek 快速版
写代码 → Claude
推理题 → GPT 推理版
成本：中等
效果：覆盖所有场景

组合 C：效果优先

text
全部用最强的模型
适合：对结果质量要求极高
成本：最高（可能是组合 A 的几十倍）

八、一句话总结

你的情况建议
不确定选什么先用 DeepSeek 快速版
结果不满意换成 Claude 或 GPT 再试
想省钱控制对话长度 + 缩短输出
要写代码Claude
要算数学GPT 推理版
要看图Gemini
要处理超长文档Gemini 或分段

核心原则：简单任务用便宜模型，复杂任务才升级。

90% 的日常使用，最便宜的模型就够了。
