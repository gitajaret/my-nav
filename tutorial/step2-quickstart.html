这页是 一条龙 ：从注册账号开始，到软件第一次正常回复为止。

中间不管你用哪个软件，基本都归到两种情况之一 ——

软件能自动获取模型 、或 不能自动获取要手填 。

要是还卡住，去 兜底教程 让别的 AI 手把手教你配。

全程只需要记住两个东西：

① 接口地址 ：绝大多数软件填 https://api.juheai.shop/v1 （Claude 系软件填 https://api.juheai.shop ， 不带 /v1，原因见下）

② API 密钥 ： sk- 开头的一串字符，注册后在控制台自己创建

1注册账号

  • 打开本站首页，点右上角「注册」。
  • 用邮箱注册（建议用常用邮箱，找回密码靠它）。
  • 注册完自动登录，进入控制台（左边一排菜单的那个页面）。

2准备余额（先小额测试）

调用按用量扣费，账户里得有余额。 建议第一次先花小钱测试 ，跑通了再充：

  • 线上：打开 余额充值页 的充值地址

（msfk.tpjzyh.cn/shop/juheai），

已上架 0.33 元 和 1 元 两种额度的兑换码 —— 买一个，正好用来测试网站稳定性。

  • 兑换：控制台 →「兑换码」页面输入即可到账。
  • 其它额度：走充值页下方的线下充值（联系客服 QQ）。

3创建 API 密钥（最重要的一步）

  • 控制台 → 左侧「API 密钥」。
  • 点「新建」，名字随便填（比如 test）。
  • 生成后立刻复制——形如 sk- 开头的一长串，离开页面就再也看不到完整内容了。先粘到记事本备用。

密钥 = 你的钱包密码。 谁拿到它谁就能花你的余额。不要发群、不要发论坛；

找客服求助时也请把中间打码（例如 sk-abc****xyz ）。

4挑一个软件并装好

按你想干什么选，点进去照着装（每个都有「没碰过命令行」的引导）：

你想干什么推荐教程
写代码 / 改项目Claude Code CLI（命令行）或 桌面端（图形）CLI · 桌面端
聊天 / 角色扮演酒馆 SillyTavern教程
不想敲命令、统一管理多个工具CC Switch（图形界面）教程
让 AI 自动干活（读文件、跑命令）DeepSeek Harness教程
把 AI 接到微信之外的聊天软件（手机也能用）OpenClaw教程

没碰过命令行的，先看 命令行入门（3 分钟）。

5填参数并测试（三种情况对号入座）

所有软件要填的东西都一样，就这三样：

字段填什么备注
接口地址 / Base URLOpenAI 兼容软件：https://api.juheai.shop/v1Claude 系软件：https://api.juheai.shopOpenAI 兼容要带 /v1，Claude 系不带。各软件该用哪种，看它教程页的说明。
API 密钥 / API Keysk-你的密钥粘贴前后不要带空格换行。
模型名 / Model如 deepseek-v4-flash、deepseek-v4-pro、gemini-3.1-pro、claude-sonnet-5-5必须逐字照抄，见 模型介绍。

区别只在「模型名怎么来」。对号入座：

情况 A：软件能自动获取模型（最省心）

典型： 酒馆（连上后模型列表自动填充）、DeepSeek Harness（「获取可用模型」按钮）、Hermes（向导会校验并列出可见模型）、OpenClaw（向导里选 Custom Provider 后会当场发一次真实请求来验证）。

  • 填好地址 + 密钥，先点「连接 / 获取模型 / 保存」。
  • 等它拉取列表 —— 出现下拉框后，选一个模型（第一次建议 deepseek-v4-flash，便宜）。
  • 保存，发一条测试消息。

成功标志：状态变绿 / 提示可见 N 个模型 / 软件正常回复。

拉取失败也不用慌：多数软件这时候允许 手动填模型名 ，直接跳到情况 B。

情况 B：软件不能自动获取模型（手动填）

典型： Claude Code（模型写进配置或用 /model 选）、Codex（ config.toml 里手写）、部分图形工具没有拉取按钮。

  • 打开 模型介绍 或控制台「可用渠道」，找到你能用的模型 id。
  • 逐字复制填进软件的模型栏 —— 大小写、连字符、数字都不能错。
  • 保存后发一条测试消息。

手动填模型最容易犯的错：

① 把「显示名」当模型名（比如填了「DeepSeek 快速版」）　② 大小写写错（ DeepSeek-V4-Flash ✗）

③ 多了空格或换行　④ 填了官方名而不是本站开放的名字（如 deepseek-chat ✗）

报 model_not_found / 「模型不存在」时，九成是这四种之一。

还卡住？让别的 AI 手把手教你配

如果上面两种情况都没搞定，最省事的兜底办法是： 打开任意一个能用的 AI （DeepSeek、豆包、Kimi、ChatGPT 都行），

把「配置求助模板」整段发给它，让它一步一步带你点。

完整的求助模板、报错追问写法和三条安全红线，都在 兜底教程 里。

怎么确认「真的走的是本站」

  • 软件正常回复了，还不够 —— 打开控制台 → 使用日志。
  • 能看到刚才那条调用的记录（模型名、token 数、扣了多少钱），才是真正走通了。
  • 日志里没有记录 = 请求没发到本站（地址或密钥不对），回到第 5 步检查。

卡住了？按这个顺序排查

现象先查什么
一直 401 / 认证失败密钥复制对了吗？变量名/字段名对了吗（OpenAI 用 API Key，Claude 系用 AUTH_TOKEN）？
模型不存在 / model_not_found模型名是不是逐字照抄的（见情况 B 的四个错误）
连接超时 / 打不开地址多没多字符、少没少 /v1；网络/代理是否拦截
有回复但使用日志没记录软件连的不是本站 —— 检查 Base URL 是否被改过
报错看不懂用兜底教程把报错喂给别的 AI；还不行就按求助三件套找客服

下一步： 跑通之后，去 命令行入门 补一补基础，

再看看 模型介绍 换更合适的模型。祝玩得开心。
