第一步：科学上网

服务器位置、选节点、测速，三步让连接又快又稳

为什么需要这一步

本站服务器在境外，走 Cloudflare 加速。你到服务器之间的网络质量，直接决定调用快不快、稳不稳。

如果你遇到下面这些情况，先做这一步：

现象说明
请求慢，首字要等好几秒线路绕远了
长回答经常断连接不稳
时不时超时网络抖动
某些时段特别卡线路拥堵

加速的三个步骤

第一步：查当前服务器位置

本站走 Cloudflare 加速，IP 对应的实际位置一直在变，所以要每次现查。

推荐做法：让 AI 帮你查。

把下面这段发给任意 AI：

text
本站域名是 api.juheai.shop，走 Cloudflare。
请告诉我这个域名当前解析到哪个地区（国家/城市）的节点，
并说明我该把代理节点选在哪个地区最合适。

或者用在线工具查：

工具地址
IP 归属地查询ping api.juheai.shop 拿到 IP 后查归属地
Cloudflare 节点查询https://api.juheai.shop/cdn-cgi/trace

打开 https://api.juheai.shop/cdn-cgi/trace 会返回一行 colo=XXX，那个三字母代码就是当前接入的 Cloudflare 节点位置（如 HKG=香港、SJC=圣何塞、NRT=东京）。

第二步：把代理节点切到那个地区

打开你的代理工具，把节点切到上一步查到的地区。

为什么：节点离服务器越近，握手和首包延迟越低。

查到 colo=建议节点地区
HKG / HND / NRT / KIX香港、日本
SJC / LAX / SEA美国西部
SIN新加坡
FRA / AMS欧洲

没有代理服务？ 需要的话联系我们获取。

第三步：测速验证

切换完节点再测，数据才准。

测法命令 / 方式
ping 测试ping api.juheai.shop
首字延迟在客户端发一句「你好」，看多久出第一个字
完整请求发一个稍长的请求，看总耗时

判断标准：

指标好一般差
ping< 100ms100-250ms> 250ms
首字< 2 秒2-5 秒> 5 秒

完整工具页

完整版带自动检测和测速按钮，可以在浏览器里直接用：

👉 打开网站加速工具页

加速无效怎么办

检查做法
节点真的切了吗打开代理工具确认当前节点
测速时节点没变切换后要重启客户端
换了节点还是一样可能是本地宽带问题，换手机热点试
一直很慢联系我们，可能是线路问题

注意：加速效果受本地网络与代理线路影响，请以实测为准。

本站不做带宽承诺，加速只是让连接更稳，不能突破你的本地带宽上限。
