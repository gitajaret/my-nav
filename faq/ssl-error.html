SSL / 证书错误（x509）

报错长这样

text
SSL certificate problem
x509: certificate signed by unknown authority
TLS handshake timeout
certificate verify failed
unable to get local issuer certificate

这是什么意思

你的电脑在跟我们建立加密连接（HTTPS）时，认为对方的证书不可信。

正常情况下证书是由权威机构签发的，你的系统认可。出现这个报错，通常是中间有人在拦截和解密你的流量。

谁在拦截

拦截者说明
代理软件部分代理会做 MITM（中间人解密）
杀毒软件「HTTPS 扫描」「网页防护」功能
公司网关公司的上网行为管理设备
抓包工具Fiddler、Charles 等

怎么解决

第一步：关掉杀毒软件的 HTTPS 扫描

在杀毒软件设置里找这几项，全部关掉：

  • HTTPS 扫描 / SSL 扫描
  • 网页防护 / 网络防护
  • 流量监控

第二步：关掉代理软件

完全退出（不是暂停）。或者把我们的域名加入代理的例外列表。

第三步：确认地址没写错

检查项正确错误
协议https://http://
结尾不加 /v1加了 /v1 或 //

第四步：更新系统证书

Windows 用户：打开「设置 → 更新和安全 → Windows 更新」，安装所有更新。证书会随系统更新。

公司电脑特别说明

如果这是公司配的电脑，很可能装了上网行为管理或证书监控软件。这种情况你自己改不了，建议：

  1. 换一台个人电脑或手机测试
  2. 用手机热点 + 手机客户端验证账号是否正常
  3. 确认账号没问题后，再找公司 IT 沟通

需要提供的信息

如果以上都不行，联系我们时提供：

  • 完整报错文字
  • 操作系统（Windows 10 / macOS / 手机）
  • 是否装了杀毒软件、代理软件
  • 是否是公司电脑
