400 请求参数错误

报 400 Bad Request、does not support reasoning effort 时看这篇

报错长这样

text
400 Bad Request
invalid request
does not support reasoning effort "none"
temperature must be between 0 and 2
消息内容为空
max_tokens 超出范围

这是什么意思

你的请求参数有问题，服务器看懂了但表示「这个参数我不能接受」。

最常见的四种

1. 推理档位不支持

text
gpt-xxx does not support reasoning effort "none"

原因：这个模型不支持你设置的推理强度。

解决：

你的设置改成
nonelow 或 medium
high / xhighmedium
开着「深度思考」关掉试试

客户端里的位置：

  • Cherry Studio：助手设置 → 推理强度
  • Cursor：Settings → Models → Reasoning
  • ChatBox：高级设置 → reasoning_effort

2. 温度参数超范围

text
temperature must be between 0 and 2
top_p must be between 0 and 1

解决：

参数允许范围推荐值
temperature0 ~ 20.7
top_p0 ~ 11
max_tokens视模型而定别设太小

3. 消息内容为空

text
消息内容为空或只有空白/标点

原因：你发的内容是空的、只有空格、只有换行，或只有标点。

解决：检查输入框里是不是真的有内容。

4. max_tokens 太大

text
max_tokens exceeds model limit

原因：你要的输出长度超过了模型上限。

解决：调小 max_tokens，或者让它分段生成。

万能解决办法：恢复默认参数

不知道哪里错了？全部恢复默认。

客户端怎么恢复
Cherry Studio助手设置 → 重置参数
ChatBox设置 → 恢复默认
Cursor删掉自定义参数
其他找「高级设置」，全部清空

参数速查表

参数作用安全值
temperature随机性，越高越发散0.7
top_p采样范围1
max_tokens最多输出多少 token4096
reasoning_effort推理强度medium 或留空
frequency_penalty重复惩罚0
presence_penalty话题惩罚0

小白建议：这些参数全部留空或默认就够了。调参数是高级玩法，调错了就是各种 400。

如果都不是这些

  • 你改了哪些参数（截图客户端设置）
  • 客户端名称
  • 模型名
