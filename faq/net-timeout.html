连不上 / 请求超时（timeout）

报 Request timed out、i/o timeout、连不上服务器时看这篇
🗓 2026-11-03⏱ 约 2 分钟📑 5 个小节
📑 本文目录
目录
报错长这样为什么会这样按这个顺序试（90% 能解决）必须用梯子怎么办还是不行？

报错长这样

text
Request timed out
dial tcp: i/o timeout
context deadline exceeded
Connection timed out
Timeout

看到这些，说明你的电脑连不上我们的服务器。请求发出去了，但一直没等到回应。

为什么会这样

大部分情况不是我们的服务坏了，而是你到我们服务器之间的路不通。常见原因有三个：

原因说明
开了梯子（VPN/代理）你的流量绕到国外再绕回来，中间容易断
当前网络有问题公司网、校园网、某些宽带会限制境外或特定端口
DNS 解析错了域名被解析到一个连不通的地址

按这个顺序试（90% 能解决）

第一步：关掉梯子

这是最常见的原因。如果你开了 Clash、V2Ray、Shadowrocket 之类的代理软件，先完全退出它，再试一次。

如果你必须挂梯子才能上网，看下面「必须用梯子怎么办」。

第二步：换网络

换法说明
换手机热点最快验证是不是当前网络的锅
换 Wi-Fi家里换公司，或反过来
手机流量直连关掉 Wi-Fi 用 4G/5G

如果用手机热点就能通，说明原来的网络有问题，不是账号或密钥的问题。

第三步：换 DNS

把电脑或路由器的 DNS 改成下面任一个：

服务商DNS
阿里223.5.5.5
腾讯119.29.29.29
Cloudflare1.1.1.1

第四步：把我们的域名设为直连

如果你用的是 Clash 等带「规则模式」的软件：

  1. 切换到规则模式（不要用全局模式）
  2. 把 juheai.shop 相关域名加入直连列表
  3. 重新连接

必须用梯子怎么办

如果你的工作环境必须开代理，做这三件事：

设置怎么做
代理模式用「规则模式」，别用「全局模式」
我们的域名加进「绕过代理 / 直连」列表
节点换一个延迟低的，别用已经超时的节点

还是不行？

按这个顺序再排查一遍：

  1. 重启客户端（很多问题重启就好）
  2. 换一台设备试（手机能不能用）
  3. 确认地址没写错：应该是 https:// 开头，结尾不要加 /v1
  4. 把「报错原文 + 你用的网络 + 时间」发给我们

小提示：如果其他网站都正常，只有我们连不上，那基本可以确定是网络线路问题，联系我们处理。
