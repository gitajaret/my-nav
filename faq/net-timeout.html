报错长这样

text
Request timed out
dial tcp: i/o timeout
context deadline exceeded
Connection timed out
Timeout

这是什么意思

你的电脑连不上我们的服务器。 请求发出去了，但一直没等到回应。

打个比方：你寄了一封信，等了很久也没收到回信。可能是路上丢了，可能是地址错了，也可能是邮局停了。

三种常见原因

原因说明占比
开了梯子（代理）流量绕到国外再绕回来，中间容易断最高
当前网络限制公司网、校园网、某些宽带会限制高
DNS 解析错了域名被解析到连不通的地址中

第一步：关掉梯子（最常见）

如果你开了 Clash、V2Ray、Shadowrocket 之类的代理软件，先完全退出它。

系统怎么完全退出
Windows托盘图标 → 右键 → 退出 / Quit
macOS顶部菜单栏 → Quit
手机多任务划掉代理 App

退出后重启客户端，再试。

第二步：换网络

换法说明
换手机热点最快验证是不是当前网络的问题
换 Wi-Fi家里换公司，或反过来
手机流量直连关 Wi-Fi 用 4G/5G

用手机热点就能通 → 说明原来的网络有问题，不是账号或密钥的问题。

第三步：换 DNS

DNS 是把域名翻译成 IP 的服务。翻译错了就连不上。

服务商DNS 地址
阿里223.5.5.5
腾讯119.29.29.29
Cloudflare1.1.1.1
114114.114.114.114

Windows 改法：

text
1. 控制面板 → 网络和共享中心 → 更改适配器设置
2. 右键你的网卡 → 属性 → 双击「Internet 协议版本 4」
3. 选「使用下面的 DNS 服务器地址」
4. 首选填 223.5.5.5，备用填 119.29.29.29
5. 确定，然后 Win+R 输 cmd，执行 ipconfig /flushdns

第四步：把我们的域名设为直连

如果你用的是 Clash 等带「规则模式」的软件：

设置怎么改
模式从「全局」切到「规则」
规则加 DOMAIN-SUFFIX,juheai.shop,DIRECT
节点换一个延迟低的

必须用梯子怎么办

如果工作环境必须开代理，做这三件事：

text
1. 代理模式用「规则模式」，别用「全局模式」
2. 把 juheai.shop 加入「绕过代理 / 直连」列表
3. 换一个延迟低的节点，别用已经超时的

第五步：测一下延迟

确认到底通不通：

text
Windows：Win+R → cmd → 输入 ping api.juheai.shop
macOS：打开终端 → 输入 ping api.juheai.shop
手机：用「网络工具」类 App 测

结果怎么看：

结果含义怎么办
有回复，延迟 < 100ms网络正常问题在别处
有回复，延迟 > 300ms线路很慢换节点
请求超时（全丢包）连不上换网络
找不到主机DNS 有问题换 DNS

超时 vs 拒绝 怎么区分

报错比方处理方向
timeout 超时敲门没人应关梯子、换网络、换 DNS
refused 拒绝开门说「不接待」关梯子、换节点

完整排查流程

text
1. 完全退出代理软件 → 重启客户端 → 试
2. 换手机热点 → 试
3. 改 DNS 为 223.5.5.5 → 试
4. ping api.juheai.shop 看结果
5. 换一台设备 → 试
6. 都不行 → 联系我们
