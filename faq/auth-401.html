401 认证失败

密钥无效、incorrect api key，多数是复制带了空格
🗓 2026-10-31⏱ 约 2 分钟📑 2 个小节

报错长这样排查顺序

报错长这样

text
401 Unauthorized
invalid api key
incorrect api key
Authentication failed

排查顺序

1. 检查首尾空格

从网页复制密钥时，很容易带上换行或空格。粘贴到客户端后，把光标放到末尾多按几次退格。

2. 重新复制一次

回控制台重新复制，不要用之前存的旧值。

3. 确认密钥没被删或停用

控制台的「密钥」页面会显示状态。如果显示已禁用，新建一个。

4. 确认格式

请求头应该是：

text
Authorization: Bearer sk-xxxxxxxx

大多数客户端会自动处理，但有些需要你手动把 Bearer 加上（注意后面有个空格）。

5. 确认填对了位置

有的客户端有两个输入框：一个是「API Key」，一个是「组织 ID」。别填反了。
