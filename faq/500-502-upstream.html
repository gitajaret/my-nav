500 / 502 上游服务错误

报 500 Internal Server Error、502 Bad Gateway 时看这篇
🗓 2026-11-03⏱ 约 2 分钟📑 7 个小节
📑 本文目录

报错长这样这是什么意思先做这一件事：等 1 分钟重试如果反复出现关于 convert_request_failed怎么确认是上游问题需要提供的信息

报错长这样

text
500 Internal Server Error
502 Bad Gateway
convert_request_failed
upstream error
bad_response_status_code
上游服务异常

这是什么意思

模型提供方那边出问题了，不是你的错，也不是我们网关的错。

码含义
500上游服务器内部错误
502上游返回了一个错误响应，网关无法处理

先做这一件事：等 1 分钟重试

上游临时故障，大部分几分钟内自动恢复。

先等一下再试一次。

如果反复出现

情况一：只有某个模型报错

说明那个模型的线路有问题：

  1. 换一个同类模型
  2. 联系我们，我们换线路

情况二：所有模型都报 502

可能是：

  • 你的密钥分组对应的上游全挂了
  • 联系我们，会切到备用线路

情况三：只有你的请求报错

可能是你的请求里有特殊内容：

  • 特别大的请求体（比如很长的文件）
  • 特殊字符
  • 换个问法试试

关于 convert_request_failed

如果报错里有这个词：

这是协议不匹配。 常见于用 Claude 客户端调 OpenAI 格式的接口，或反过来。

你在用什么需要什么分组
Claude Code、Claude 客户端支持 Anthropic 协议的分组
ChatGPT、Cherry Studio、Cursor支持 OpenAI 协议的分组

解决办法：换一个协议对得上的分组密钥。

怎么确认是上游问题

检查方法
换个模型试试别的模型能用 → 是这个模型的问题
换个时间试试过一会好了 → 上游临时故障
问一下别人大家都这样 → 上游故障

需要提供的信息

联系我们时：

  • 完整报错（含状态码）
  • 模型名
  • 出现时间
  • 是否换模型试过
  • 出现频率

上游故障我们只能等他们恢复，或者切到备用线路。这两件事我们都会尽快做。
