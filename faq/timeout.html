连接超时、连不上

报错 timeout、Connection refused 时按这个顺序排查
🗓 2026-10-31⏱ 约 3 分钟📑 3 个小节
📑 本文目录
目录
报错长这样按顺序试这几步还是不行？

报错长这样

text
Request timed out
dial tcp: i/o timeout
Connection refused
connection reset by peer

按顺序试这几步

1. 关掉梯子（VPN/代理）

这是最常见的原因。挂梯子会让请求绕远路，反而不稳。先关掉再试。

2. 换网络

用手机热点试一下。如果热点能通、Wi-Fi 不通，就是当前网络的问题（公司网络、校园网常有端口限制）。

3. 换 DNS

改成 223.5.5.5（阿里）或 1.1.1.1（Cloudflare）。

4. 检查代理软件的规则

如果必须挂梯子，把我们的域名加入直连白名单，别让它走代理。

还是不行？

把「客户端名称 + 完整报错 + 发生时间」发给客服。别只说「连不上」，那样没法定位。
