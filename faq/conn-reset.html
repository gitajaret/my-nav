连接被拒绝 / 连接中断（Connection refused）

报错长这样

text
Connection refused
connection reset by peer
EOF
Failed to connect
Connection closed

这是什么意思

连接被拒绝了，或者连接建立到一半被人掐断了。

跟「超时」不一样：

报错区别
超时 timeout一直等，没等到回应（路太远或堵了）
拒绝 refused对方直接说「不接」（或中间有人拦截）

最常见的原因：梯子

90% 的 Connection refused 都是因为开了代理软件。

代理软件会把你的请求转发到国外节点，节点再连我们。这个过程中：

  • 节点可能拒绝连接
  • 节点到我们的线路可能被掐
  • 节点本身可能已经挂了

解决办法：完全退出代理软件（不是暂停，是退出进程），然后重试。

如果必须用代理

设置做法
模式规则模式（Rule）
我们的域名加到直连 / DIRECT 规则
节点换一个，或换协议（如 Trojan 换 SS）

其他可能原因

1. 客户端地址写错

确认 Base URL 填的是：

text
https://api.juheai.shop

注意：

  • 用 https://，不是 http://
  • 结尾不要加 /v1（多数客户端会自动补，加了会变成 /v1/v1）

2. 公司或学校网络限制

有些企业网络会拦截非常规端口或境外流量。用手机热点测试，如果通了就是这个原因。

3. 杀毒软件拦截

部分杀毒软件会拦截 HTTPS 请求。临时关闭「网页防护」试试。

排查步骤

text
1. 退出所有代理软件 → 重试
2. 换手机热点 → 重试
3. 重启客户端 → 重试
4. 换一台设备 → 重试
5. 还不行 → 截图报错联系客服

排查完还是不行

把这几样发给我们：

  • 报错原文（完整截图）
  • 你用的客户端名称
  • 你的网络环境（家里宽带 / 手机热点 / 公司网）
  • 出问题的具体时间
