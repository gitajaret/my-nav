报错长这样

text
Connection refused
connection reset by peer
EOF
Failed to connect
Connection closed
Remote end closed connection without response

这是什么意思

连接被拒绝了，或者连接建立到一半被人掐断了。

跟「超时」不一样，这是很多人搞混的地方：

报错打个比方区别
超时 timeout敲门没人应一直等，没等到回应
拒绝 refused敲门后有人说「不接待」对方直接拒绝

八成是梯子（代理软件）

这是最高频的原因，先查这个。

代理软件的工作方式是：你的请求 → 转发到国外节点 → 节点再连我们。

这个链路里有三个环节都可能「拒绝」：

环节出什么问题
你的电脑 → 代理节点节点挂了、节点拒绝了连接
代理节点 → 我们的服务器节点到我们的线路被掐
我们的服务器 → 返回响应回程被打断（EOF）

正确做法：完全退出代理

注意是「退出进程」，不是「暂停」或「切换节点」。

系统怎么完全退出
Windows右下角托盘图标 → 右键 → 退出 / Quit
macOS顶部菜单栏图标 → Quit
手机多任务里划掉代理 App

退出后重启你的客户端，再试一次。

必须用代理怎么办

如果你的工作环境必须挂代理，按这样设置：

设置项应该选
代理模式规则模式（Rule），不要用全局（Global）
我们的域名加入直连 / DIRECT 规则
节点换一个延迟低的，别用已经卡顿的

规则模式的写法参考（Clash）：

text
rules:
  - DOMAIN-SUFFIX,juheai.shop,DIRECT
  - DOMAIN-SUFFIX,juheai.shop,DIRECT

第二步：确认客户端地址没写错

地址错了也会报连接失败。核对：

检查项正确常见错误
协议https://写成 http://
域名api.juheai.shop拼错、多空格
结尾不加 /v1（多数客户端自动补）加了变成 /v1/v1

正确写法：

text
https://api.juheai.shop

第三步：换网络测试

换法说明
手机热点最快验证是不是当前网络的问题
换 Wi-Fi家里换公司，或反过来
手机 4G/5G 直连关 Wi-Fi 用流量

如果用手机热点就能通 → 说明是你原来的网络（公司网、校园网、宽带）有问题。

第四步：排查本地干扰

干扰源怎么处理
杀毒软件临时关闭「网页防护」「网络防护」
防火墙检查是否拦截了 https 出站
公司网关这种情况自己改不了，换设备试

四种报错的具体含义

看到具体哪一种，对应处理更精准：

报错原文含义优先处理
Connection refused对方端口不接关代理
connection reset by peer连接被对方重置关代理 + 换网络
EOF连接中途断开换网络（线路不稳）
Connection closed连接被关闭检查客户端超时设置

排查流程（照着走）

text
第 1 步：完全退出代理软件 → 重启客户端 → 试
  ↓ 还不行
第 2 步：换手机热点 → 试
  ↓ 还不行
第 3 步：核对地址 https://api.juheai.shop（无 /v1）
  ↓ 还不行
第 4 步：临时关杀毒软件网页防护 → 试
  ↓ 还不行
第 5 步：换一台设备（手机 / 另一台电脑）→ 试
  ↓ 还不行
第 6 步：联系我们，带上下面这些信息

联系我们时提供

#信息为什么重要
1报错原文（完整）不同报错原因不同
2客户端名称和版本配置方式不同
3网络环境：家里宽带 / 公司网 / 手机热点定位是否网络限制
4是否开了代理最高频原因
5出问题的具体时间查日志定位

和「超时」怎么区分

这两个报错经常一起出现，记住区别：

text
超时 → 路太远或堵了，一直等不到
拒绝 → 到门口了，人家不让你进

超时的解法：关梯子、换网络、换 DNS
拒绝的解法：关梯子（彻底退出）、换节点
