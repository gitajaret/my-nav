404 模型不存在或不支持

报错长这样

text
404 Not Found
Model "xxx" is not supported by any configured account in this group
model_not_found
The model does not exist
Invalid model
模型不存在

这是什么意思

服务器说：你点名的这个模型，我这儿没有。

就像你去餐厅点菜，说了个菜单上没有的菜名。

九成是模型名写错了

模型名区分大小写，一个字母、一个横杠、一个点都不能错。

正确做法：从模型广场复制

text
1. 登录控制台 https://api.juheai.shop
2. 进入「模型广场」
3. 找到你要用的模型
4. 点「复制」按钮（不要手打！）
5. 粘贴到客户端的模型名输入框

常见写错对照

错误写法正确写法错在哪
GPT-4gpt-4大小写
deepseek_v4deepseek-v4下划线 vs 横杠
claude-3.5claude-3-5-sonnet少了后缀
gpt4gpt-4少了横杠
DeepSeek-V4deepseek-v4大小写
gemini-3.1progemini-3.1-pro少了横杠

第二步：确认分组支持这个模型

即使模型名对了，你的密钥所属分组也必须支持它。

怎么查

text
1. 后台 →「模型广场」
2. 看这个模型标的是哪个分组
3. 后台 →「API 密钥」→ 看你的密钥属于哪个分组
4. 两者要对得上

分组不对怎么办

情况处理
密钥分组没有这个模型用支持该模型的分组新建密钥
不确定该用哪个分组看模型广场的分组标注

第三步：模型可能真的没有

如果模型广场里也搜不到：

做法说明
换一个同类模型比如都是 GPT 系列的另一个
联系我们说出你想要的模型，我们评估接入

各客户端怎么填模型名

客户端填在哪注意
Cherry Studio模型服务 → 模型列表 → 手动添加选「自定义模型」
ChatBox设置 → 模型 → 自定义模型名别用下拉列表
NextChat设置 → 模型 → 自定义逗号分隔多个
Cursor设置 → Models → 添加模型需要精确名称
Claude Code命令行参数 --model区分协议

有些客户端有「下拉列表」，但列表可能是旧的缓存。选「自定义」然后手动粘贴最可靠。

检查清单

遇到 404 时逐项核对：

text
□ 模型名是从模型广场复制的吗？
□ 大小写完全一致吗？
□ 横杠、点、数字都没错吗？
□ 首尾有没有多余空格？
□ 密钥所属分组支持这个模型吗？
□ 模型广场里能搜到这个模型吗？
□ 客户端里选的是「自定义模型」吗？

一个真实排查顺序

text
第 1 步：复制模型名 → 还是 404？
第 2 步：换个模型试 → 换了能用？说明是这个模型的问题
第 3 步：查分组是否匹配 → 不匹配就换分组建密钥
第 4 步：模型广场搜 → 搜不到就是真没有
第 5 步：都不行 → 联系我们
