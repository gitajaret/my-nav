504 网关超时（上游超时）

报 504 Gateway Timeout、524、upstream timeout 时看这篇

报错长这样

text
504 Gateway Timeout
524 A timeout occurred
upstream timeout
origin_response_timeout
网关超时

这是什么意思

上游服务器处理你的请求太久了，中间等不及，主动断开了。

跟「连接超时」的区别：

报错比方区别
timeout 连接超时电话打不通根本连不上
504 网关超时电话通了但对方一直不说话连上了，但处理太慢

什么情况容易超时

情况说明占比
超长上下文传了几万甚至几十万 token最高
复杂推理任务让 AI 做深度思考高
生成长文本一次要写几千字高
上游繁忙大家都在用，排队中

第一步：简化问题

这是最有效的办法：

做法效果
开新对话不带旧历史，立省大量 token
拆成几步问复杂任务分阶段做
缩短输出要求「简要说明」而不是「详细展开」
删掉没用的附件只保留必要内容

例子对比

text
❌ 会超时的问法：
把下面这份 3 万字的报告全文翻译成英文，
并逐段分析论点、列出所有数据、给改进建议，越详细越好。

✅ 不会超时的问法（分三次做）：
第 1 次：把这份报告翻译成英文
第 2 次：列出报告里的关键数据和论点
第 3 次：针对这 5 个论点给改进建议

第二步：换模型

不同模型的响应速度差别很大：

模型类型速度适合
小参数快速模型最快简单问答、翻译
中等模型中一般写作、分析
推理型模型最慢复杂逻辑、数学

急着用就先换快的，复杂任务再换回来。

第三步：等一会重试

上游繁忙是暂时的，等 1-2 分钟再试。

第四步：关掉流式输出

有时非流式反而更稳定（不会中途断）。

客户端怎么关
Cherry Studio设置 → 关闭「流式输出」
ChatBox设置 → 高级 → 关 Stream
NextChat设置 → 关 Stream

关于 524

524 是 Cloudflare 特有的错误码，含义是「源站响应超时」。

看到 524 说明：

text
1. 肯定是请求耗时太长
2. 简化问题（见第一步）
3. 反复出现就联系我们

长文档怎么处理

如果必须处理很长的内容：

做法说明
分段处理每次处理一部分，最后汇总
先摘要再细问先让它总结，再针对要点问
用长上下文模型模型广场会标注上下文长度
别一次全塞越短越快

什么时候是我们的问题

现象判断怎么办
简单问题也 504上游故障联系我们
只有某个模型 504该模型线路问题换模型或反馈
高峰期频繁 504容量问题可反馈，避开高峰
复杂任务偶尔 504正常简化问题

和 500/502 的区别

text
500/502 → 上游崩了或返回错数据 → 等，或换模型
504     → 上游没崩，但处理太慢 → 简化问题，或分段

联系我们时提供

#信息
1完整报错
2模型名
3大概多长的对话（或多少字的文档）
4是简单问题还是复杂任务
5出现频率（每次 vs 偶尔）
