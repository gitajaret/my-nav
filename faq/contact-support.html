为什么需要这些信息

「报错了」这五个字，我们没法帮你修。

同样的「用不了」，可能是密钥问题、网络问题、余额问题、线路问题，解法完全不同。

提供完整信息，能让我们一次定位、直接给答案。

必须提供的四项

#信息为什么需要例子
1账号邮箱定位你的账户you@example.com
2报错原文最快定位原因完整的报错文字或截图
3客户端名称不同客户端配置不同Cherry Studio / Cursor
4模型名定位账号池deepseek-v4.1-flash

加分项（提供了更快）

信息例子
出问题的具体时间2026-11-03 14:20 左右
已经试过哪些办法关梯子、换网络、换模型
是否每次都这样一直这样 vs 偶尔
换模型是否正常换 Claude 能用，GPT 不行
你用的分组模型广场上标的

千万不要发

不要发原因
完整密钥 sk-xxxxx...泄露会被盗刷
账号密码我们自己也不会问你要
支付密码绝不需要

我们核对身份只需要邮箱，不需要密码。

如果有人说要你的密码，那一定是骗子。

怎么复制报错

方法一：截图（推荐）

把客户端里的报错完整截下来，包括：

  • 报错文字
  • 状态码（如果有）
  • 出现的时间

方法二：复制文字

如果客户端能选中文字，直接复制粘贴。比截图更好，因为我们能搜索关键词。

方法三：看客户端日志

部分客户端有日志功能：

客户端日志位置
Cherry Studio设置 → 关于 → 日志
ChatBox设置 → 高级 → 导出日志
Cursor命令面板 → Developer: Show Logs

排查顺序（自己先走一遍）

发给我们之前，先按这个顺序试一遍，能解决 90%：

text
1. 看报错文字，对照本站文档找一样的
2. 有关键词就能定位：
   「余额」→ 充值
   「401 / 密钥」→ 重新复制密钥
   「模型」→ 核对模型名
   「超时 / 连接」→ 关梯子、换网络
   「429」→ 等一分钟
3. 网络：关梯子 → 换手机热点 → 换 DNS
4. 配置：对照「客户端配置自查清单」逐项核对
5. 还不行 → 带上完整信息找我们

我们会怎么处理

情况我们的动作大概时间
配置问题指给你怎么改立即
余额问题告诉你怎么充立即
线路故障切换备用线路几分钟到几十分钟
上游故障等上游恢复或换线路看上游
账号问题后台协助查尽快

一句话总结

症状一句话解决
超时、连不上关梯子，换手机热点
401 认证失败重新复制密钥，去掉空格
余额不足充值
模型不存在从模型广场复制模型名
429 太频繁等 60 秒，降并发
回答断一半重发；关梯子；关流式
内容被拦截换措辞；别碰逆向/越狱
模型暂不可用等 1-2 分钟或换模型
参数错误恢复默认参数
