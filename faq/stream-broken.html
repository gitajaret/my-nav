报错长这样怎么办

报错长这样

text
stream disconnected before completion
stream ended before a terminal event
Upstream response stream was interrupted
504 Gateway Timeout

怎么办

1. 直接重发

多数情况重试就好，只是网络抖动。

2. 总在同一处断 → 换问法

如果每次都断在相同位置，说明是那段内容触发了问题（可能是敏感词，也可能是上游解析不了）。

3. 关掉梯子或换网络

网络不稳是流式中断的主因。

4. 超长回答分段要

让它先写第一部分，再继续写第二部分。一次生成几万字很容易中途断。

5. 关掉客户端的流式输出

有些客户端在流式模式下有 bug，改成非流式（关闭 Stream 开关）再试。

6. 超时设长一点

客户端超时至少给 60 秒，复杂任务给 300 秒。
